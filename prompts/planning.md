# PLAN_RO: one structured planning request

Return one JSON object with action `retain`, `revise`, or `withdraw`, and at most
five lesson objects. A revision contains target, mod_type, category_detail,
diagnosis, change, expected_effect, and evidence_run_ids. The harness assigns
owner, frozen parent, logical plan identity, and immutable version identity.
Include every own formal record in the exact target/mod_type class, including
failed evaluations and zero gains. Use only the frozen own/public context.

Propose the change before editing code. This request has no shell, arbitrary
scratch execution, candidate editor, or panel access. Numeric value and bid
are recomputed by MAESTRO from complete own formal history. Synthetic schema
examples are not measured evidence. Retain an eligible pending version without
revising its text; withdraw if no useful hypothesis remains.
